1\) Registro de pedidos



Requisito 1: O sistema deve permitir que o vendedor registre o pedido do cliente.



Fonte: Conversa com o vendedor. Fonte humana, nível operacional, usuário vendedor.



Requisito 2: O sistema deve calcular o valor total da compra.



Fonte: Conversa com o vendedor. Fonte humana, nível operacional, usuário vendedor.



Requisito 3: O sistema deve registrar a forma de pagamento escolhida pelo cliente.



Fonte: Política da empresa sobre formas de pagamento. Fonte não humana, categoria documentação.



\------------------------------------------------------------------------------------------------------------------



2\) Cadastro e remoção de produtos



Requisito 1: O sistema deve permitir que o administrador cadastre novos produtos.



Fonte: Conversa com o administrador. Fonte humana, nível operacional, usuário administrador.



Requisito 2: O sistema deve permitir que o administrador altere as informações dos produtos.



Fonte: Conversa com o administrador. Fonte humana, nível operacional, usuário administrador.



Requisito 3: O sistema deve permitir que o administrador remova produtos que não são mais vendidos.



Fonte: Regras da empresa para produtos. Fonte não humana, categoria documentação.



\------------------------------------------------------------------------------------------------------------------



3\) Controle de estoque



Requisito 1: O sistema deve registrar quando um produto sair do estoque após uma venda.

Fonte: Conversa com o responsável pelo estoque. Fonte humana, nível operacional, usuário responsável pelo estoque.



Requisito 2: O sistema deve permitir registrar a entrada de novos produtos no estoque.

Fonte: Conversa com o responsável pelo estoque. Fonte humana, nível operacional, usuário responsável pelo estoque.



Requisito 3: O sistema deve mostrar a quantidade disponível de cada produto.

Fonte: Regras de controle de estoque da empresa. Fonte não humana, categoria documentação.
