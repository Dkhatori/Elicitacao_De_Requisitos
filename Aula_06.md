**1) Empatia -** 



**R=** Por que eu tenho dificuldade para acordar no horário mesmo colocando o despertador antes de dormir?



**2) Definição -** 



**R=** Eu tenho dificuldade para acordar no horário porque muitas vezes desligo o despertador e volto a dormir, fazendo com que eu me atrase para meus compromissos.



**3) Ideação -**



**R=** Despertador inteligente: o sistema toca o alarme e, caso eu desligue, ele toca novamente alguns minutos depois.



&#x20;  Despertador com desafio: para desligar o alarme, eu preciso realizar uma pequena tarefa, como resolver uma conta matemática ou responder uma pergunta.



&#x20;  Alarme gradual: o sistema aumenta o volume do alarme aos poucos e também acende a tela ou uma luz para ajudar a despertar.



**4) Escolha -**



**R=** Despertador com desafio, pois me obrigaria a realizar uma atividade ao acordar, diminuindo a chance de desligar o despertador e voltar a dormir.



**5) História de usuário -** 



**R=** Como usuário, quero configurar um horário para o despertador, para conseguir acordar no horário que preciso.



&#x20;  Como usuário, quero que o despertador exija um pequeno desafio para ser desligado, para evitar que eu desligue o alarme e volte a dormir.



&#x20;  Como usuário, quero escolher diferentes tipos de desafios, para utilizar uma opção que seja adequada para mim.



**6) Critério de aceitação -**



R= Dado que o usuário configurou um horário para acordar, quando chegar o horário definido, então o despertador deve tocar.



&#x20;  Dado que o despertador está tocando, quando o usuário tentar desligá-lo, então o sistema deve apresentar um desafio antes de permitir que o alarme seja encerrado.



&#x20;  Dado que o usuário respondeu corretamente ao desafio, quando confirmar a resposta, então o sistema deve desligar o despertador.
